# Google Sheets Database Structure

Create or let the app initialize these sheets in the bound spreadsheet.

## Items

| Column | Description |
| --- | --- |
| ID | UUID generated by Apps Script |
| Item Code | Auto generated code such as BRG0001 |
| Item Name | Souvenir item name |
| Description | Optional notes |
| Initial Stock | Starting stock |
| Current Stock | Read-only stock updated by transactions |
| Minimum Stock | Low stock threshold, default 10 |
| Created At | Created timestamp |
| Updated At | Updated timestamp |
| Is Active | TRUE/FALSE |

## Transactions

| Column | Description |
| --- | --- |
| ID | UUID generated by Apps Script |
| Date | Transaction date |
| Item ID | Reference to Items.ID |
| Transaction Type | IN or OUT |
| Quantity | Positive quantity |
| PIC | Person in charge |
| Description | Purpose/description |
| Created At | Created timestamp |
| Created By | Google account email |

## Users

| Column | Description |
| --- | --- |
| ID | UUID/manual ID |
| Name | User display name |
| Email | User email |
| Role | Admin/Staff/Viewer |
| Is Active | TRUE/FALSE |
| Created At | Created timestamp |

## Settings

| Key | Value |
| --- | --- |
| LOW_STOCK_DEFAULT | 10 |
